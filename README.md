# Кирилл · продуктовый аналитик

Продуктовый аналитик с фокусом на ML и LLM. Отвечаю на продуктовые вопросы цифрами: метрики, A/B-эксперименты, EDA. Собираю RAG-пайплайны и LLM-агентов — от парсинга данных до оценки качества поиска.

## Чем занимаюсь

**Аналитика продукта**
Метрики и воронки, дизайн экспериментов (размер выборки, A/A-тесты, стратификация), дашборды, поиск аномалий в данных.

**ML и LLM**
RAG: чанкинг, эмбеддинги, гибридный поиск, Qdrant. RecSys: content-based и гибридные рекомендации с честным сравнением по HR@5 / NDCG@5. ASR: Whisper, faster-whisper, GigaAM. NLP и CV: классификация, кластеризация, разбор документов.

**Инструменты**
Python (pandas, numpy, scikit-learn, PyTorch), SQL, ClickHouse, Jupyter, Docker, Jira REST API, n8n.

## Что в работе

- **RAG-бенчмарк по нормативным документам** — гибридный поиск (BM25 + эмбеддинги) в Qdrant, замер retrieval-метрик на правовой базе.
- **RAG по PDF-корпусу** — пайплайн индексации с чанкингом и генерацией вопросов через LLM, docker-compose и CI.
- **Пайплайн транскрибации** — ffmpeg → ASR с таймкодами → LLM-выжимка по блокам интервью.
